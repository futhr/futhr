# Security policy

## Supported version

The deployed version represented by the current `main` branch is supported. Older
commits, forks, previews, and modified deployments are not supported by this
repository.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory flow when it is available for this repository, or email
[hi@futhr.io](mailto:hi@futhr.io) with:

- the affected URL, commit, component, or dependency;
- reproduction steps and the expected security impact;
- any proof of concept, logs, or screenshots with secrets removed; and
- whether the issue is known to have been exploited.

Reports are acknowledged and triaged as maintainer capacity allows. This repository
does not promise a response or remediation service level.

Please allow a reasonable remediation and deployment period before public
disclosure. Do not access data that is not yours, degrade the service, use social
engineering, or perform denial-of-service testing.

## Vulnerability handling

Maintainers will preserve the report, reproduce the issue when safe, assess affected
artifacts and dependencies, prepare a fix, test the production build, and publish an
advisory when users need to take action. This policy does not promise a bug bounty.
