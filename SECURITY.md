# Security policy

The deployed site and the current `main` branch are in scope. Forks and modified
deployments are not.

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository, or email
[hi@futhr.io](mailto:hi@futhr.io) with the affected URL or file, steps to
reproduce, and the impact you expect. Strip secrets from logs and screenshots.

This is a one-person project. Reports are read and answered as time allows, with
no response-time promise and no bounty. Please allow a fix to be deployed before
publishing. Do not access data that is not yours or test denial of service.
