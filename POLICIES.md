# Repository policies and notices

This file is a navigation aid, not a GitHub-recognized community-health file or a
legal-compliance certificate. The policies apply only to this repository and its
deployed showcase. Linked projects and services have their own maintainers, release
processes, support boundaries and terms.

## GitHub community files

GitHub recognizes these files directly from the repository:

- [Contribution policy](CONTRIBUTING.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Security policy](SECURITY.md)
- [Support policy](SUPPORT.md)

Their locations follow GitHub's documented community-health file conventions. Their
project-specific wording is maintained here; GitHub does not approve or legally
validate it.
